# Anyway Plan

A small planning canvas for developers. TanStack Start, React, Tailwind CSS, and React Flow, following `design.md` with a gray canvas, white surfaces, quiet type, and local Geist fonts.

```sh
bun install
bun run dev:plan
```

Open <http://127.0.0.1:3004>. Click premade blocks to add them, drag to arrange, and connect their handles by dragging or clicking each endpoint. Select blocks or connections to edit them; Delete removes selections. React Flow provides keyboard selection, movement, pan, zoom, and fit controls.

One draft is saved in this browser. Download/Open transfers a JSON plan. Browser storage can be cleared; keep a downloaded copy of work you want to retain. Multiple tabs are independent editors; use one tab per browser draft.

## AI tools

Choose **Use AI → Enable AI tools** in a browser with native WebMCP support. The app registers:

- `plan_read`: returns the current graph and available block kinds.
- `plan_add`: adds blocks and connections in one validated call, preserving existing content. Read the canvas first and choose unused IDs.

Example instruction for your browser agent: “Read this plan. Add a worker below the API and connect the API to it with a jobs connection.”

Enabling tools permits the browser agent to read and extend this canvas directly. AI processing depends on your agent and may happen in the cloud. There is no embedded model or chat. Disable tools from the toolbar. Opening another plan disables tools; leaving the page unregisters them. Manual editing works without WebMCP.

Registration follows the [document.modelContext API](https://developer.chrome.com/docs/ai/webmcp/imperative-api). Verified in Codex's in-app browser on September 9, 2026: native tool discovery, reading the canvas, adding and connecting a storage block, rejecting a missing endpoint without changing the graph, and removing tools on disable. Unit tests additionally cover invalid batches, file validation, and registration cleanup. Other browsers and agents have not been tested.

## Checks

```sh
bun run test:plan
bun run build:plan
bun run --cwd apps/plan check-types
bun x ultracite check apps/plan
```

The route tree is generated by Vite on the first dev/build run. A Cloudflare Worker configuration is included, matching MD's deployment target, with no database or account required. This scaffold has not been deployed.
