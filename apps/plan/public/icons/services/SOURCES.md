# Service icon sources

- `r2.svg`: [Cloudflare documentation](https://github.com/cloudflare/cloudflare-docs/blob/356ad209f77739171478e7633584ad20cb3f5552/src/icons/r2.svg). The monochrome glyph is displayed in Cloudflare orange through a CSS mask.
- `route53.svg`, `lambda.svg`, `app-runner.svg`, `rds.svg`: AWS architecture artwork mirrored by [theSVG](https://github.com/glincker/thesvg/tree/19107207407cd85eaebd5a84b2ba7084336c69fc/public/icons). [AWS architecture icons](https://aws.amazon.com/architecture/icons/).
- `cloud-run.svg`: Google Cloud product artwork mirrored by the same theSVG revision. [Google Cloud icons](https://cloud.google.com/icons).

The SVG artwork is stored unchanged. Product names and artwork belong to their respective owners.
