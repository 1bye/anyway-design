## Working in the lab

Choose a component using the lab’s sidebar. Props and environment controls update its preview, Code shows a copyable usage example, and Reset restores the demo’s initial state.

Native comparison opens the existing reference study in the same workbench. Use its back link to return to components. Open the lab in a separate tab when you need more room for desktop and Finder compositions.
