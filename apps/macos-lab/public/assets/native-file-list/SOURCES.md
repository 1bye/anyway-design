# Native Finder list reference

`tahoe-finder-dark.jpg` was captured from a live Finder window on 20 October
2026, running macOS Tahoe 26.6.2 (25G83), through the computer-use screenshot
API. It is a 1840 × 1380 JPEG at 2× density (920 × 690 logical pixels).
The study displays source rectangle x=0, y=176, width=1840, height=696.
The sidebar was hidden before capture. No personal documents or locations
appear in the image. Apple's ownership of native interface artwork is unchanged.

The temporary fixture directory was `/private/tmp/Anyway-List-Reference`.
It contained two empty folders (Archive, Design resources), two generated
599-byte PDFs (Agreement for Services.pdf, Project brief.pdf), generated
text files (Meeting notes.txt, 2400 bytes; Read me.txt, 480 bytes), a generated
158-byte ZIP (Round one.zip), and two copies of the lab's `clouds.webp`
(Photo 2.webp, Photo 10.webp; 46482 bytes each). File contents were demo text
and existing demonstration imagery, not user documents.

Modification times are 12 October 2026, hourly from 09:41 to 17:41 local time,
in lexicographic fixture-name order. The live data module records the matching
timestamps and Finder display labels. Finder is active in dark appearance,
sorted by Name ascending, with Agreement for Services.pdf selected.

The normalized list has 10px side insets, a 28px header, a 5px gap before
20px rows, and rounded full-row selection. Measured Name / Date Modified /
Size / Kind widths are 500.5 / 181.5 / 96.5 / 121.5 logical pixels.
`manifest.json` records these dimensions and the captured state.

Finder's image/PDF previews and installed-app document icons are deliberately
retained in the native side. The React side uses the reusable package's generic
native file-type icons; no photographed rows, text, or selection are used there.
Light, inactive, resized, sorted, and tagged states in the study are live
interaction examples rather than additional native captures.

Apple's [folder-view guide](https://support.apple.com/en-ke/guide/mac-help/mchldaafb302/mac)
documents list columns and header sorting. The actual local capture above is
the visual baseline rather than a list image from that guide.
