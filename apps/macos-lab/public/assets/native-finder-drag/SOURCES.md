# Tahoe Finder drag feedback

Captured on 21 October 2026 through the native computer-use window screenshot
API on this Mac running Tahoe 26.6.2. The user held a drag in Finder after
pointer automation could select files but could not start a native drag.

`tahoe-folder-target.png` is an unretouched 696 × 468-pixel crop of that
1840 × 1380-pixel capture, at x=506, y=108. It represents 348 × 234 logical
points. Archive shows folder feedback, with Clouds.webp selected. macOS's
floating drag image and the actual desktop pointer are separate surfaces;
they are absent from this window capture. Do not use this asset to claim
calibration of the drag stack or spring-loading timing.

Only generated demonstration files under `/private/tmp/Anyway-Drag-Reference`
were used: Archive/, Clouds.webp, Design resources/Brand/Colors.txt,
Design resources/Read me.txt, Notes.txt, Photos/, Project brief.txt. Clouds.webp
is the lab's existing asset, copied byte for byte. Text files contain repeated
original demonstration text. No user documents were modified.

The live side reuses MacFinder and the package's existing generic folder icon.
The text thumbnails are the earlier lab fixture, so their content differs.
Native folder feedback and icon layout are compared at a shared scale in
`/?view=finder-drag-reference`. Multi-item drag previews, other views, and the
800ms hover delay remain estimates pending a full desktop recording.
