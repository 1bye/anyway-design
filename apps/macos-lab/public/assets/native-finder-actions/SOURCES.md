# Tahoe Finder file actions

Captured locally from Finder on macOS Tahoe 26.6.2 (25G83), using only generated files in `/private/tmp/Anyway-Actions-Reference`. No personal files appear.

Each PNG is the unchanged Name-column crop (0, 108, 1020, 508) of a 1840×872 native Finder window capture. Display at 510×200 logical pixels. Sidebar hidden; list view; Name ascending; dark appearance.

- `tahoe-duplicate.png`: ⌘D on Notes.txt; Notes copy.txt selected.
- `tahoe-paste.png`: Copy Notes.txt, open Archive, ⌘V; copied file unselected.
- `tahoe-move.png`: Copy Project brief.txt, open Archive, ⌥⌘V; moved file unselected.
- `tahoe-trash.png`: ⌘⌫ on Notes.txt; next row Project brief.txt selected.
- `tahoe-undo-trash.png`: ⌘Z restores Notes.txt and selects it.
- `tahoe-redo-trash.png`: ⇧⌘Z removes Notes.txt again.

Native Edit menu accessibility labels confirmed Undo Duplicate of “Notes.txt”, Paste Item, and Move Item Here. Native popup menu pixels and animation timing are not part of these captures. The native .txt icons reflect the Mac’s Sublime Text association; the React example uses generic document icons.
